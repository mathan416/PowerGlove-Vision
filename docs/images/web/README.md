# Web gesture illustrations

Generated by `scripts/build-help-images.py` using Pillow. Run it after editing the
original artwork under `docs/images/gestures`.

Help and Glove Academy requests automatically use these compact PNG copies.
Individual gestures are at most 320 pixels on their longest side; multi-gesture
sheets are at most 960 pixels. Aspect ratio and transparency are retained.
HTML display dimensions stay unchanged. PDF generation continues to use the
full-resolution originals, which must remain in place.
